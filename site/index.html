Source code →

C# / .NET 10: the domain model and WMS services, the ASP.NET Core server edition and the Blazor browser edition.

Two editions, one WMS

The browser edition runs the WMS services compiled to WebAssembly, with its database in the browser, for demonstration and training. The server edition is the same WMS as an ASP.NET Core service with an HTTP API for the real cell, backed by SQLite. To run it with the .NET 10 SDK:

dotnet run --project src/Logistics.Wms.Api --urls http://localhost:5213

Then open http://localhost:5213/ and press Start simulation.
