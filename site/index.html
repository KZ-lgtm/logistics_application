C# / .NET 10 WMS: orders, rolling waves, ASRS tasking, picking, sortation, restock, inventory.

Run the WMS

The WMS is an ASP.NET Core server with a live dashboard, so it runs locally rather than on GitHub Pages. With the .NET 10 SDK:

dotnet run --project src/Logistics.Wms.Api --urls http://localhost:5213

Then open http://localhost:5213/ and press Start simulation.
